# 텍스트 이모지 효과 설정 UI 개선 계획

## 개선 요청 사항

### 1. 애니메이션 설정 UI 구조 개편

#### As-is
- 애니메이션 속도/강도 슬라이더가 맨 위에 위치
- 그 아래 불필요한 "공통 설정" 섹션 (지속시간, 반복횟수, 애니메이션 방향)이 추가됨
- 그 아래 효과별 개별 설정들이 각각 분리된 박스로 표시됨
- 맨 아래 기존 "슬라이딩"효과용 설정들(텍스트 색상, 글자 크기, 수직 오프셋, 속도, 간격)이 그대로 유지됨
- 공통설정과 개별설정이 혼재되어 있고, 설정 순서가 비논리적임

#### To-be
- 모든 설정을 효과별로 필요한 설정들을 분석하여 정리
- 기존 스타일(단순한 슬라이더와 버튼)을 유지하며 공통설정/개별설정 구분 없이 통합
- 효과별로 실제 필요한 설정만 표시
- 설정 순서를 논리적으로 재배치

### 2. 불필요한 공통 설정 제거

#### As-is
- 지속시간(duration) 설정이 있음
- 반복횟수(repeat) 설정이 있음
- 애니메이션 방향(direction) 설정이 있음

#### To-be
- 지속시간과 반복횟수 설정 완전 제거 (무한 루프만 제공하고, 루프 시간은 다른 변수로 결정됨)
- 애니메이션 방향 설정 필요성 재검토 후 필요한 효과에만 개별적으로 적용

## 사용자 답변 반영

### 1. 기존 스타일의 의미
✅ **확인됨**: 기존 슬라이딩 효과에서 사용하던 단순한 슬라이더 스타일을 의미

### 2. 효과별 설정 통합 방식
✅ **확인됨**: 박스 구분 없이 하나의 영역에 플랫하게 배치, 효과 변경 시 불필요한 설정은 숨김 처리

### 3. 애니메이션 방향 설정
✅ **확인됨**: 정방향/역방향/왕복 설정은 공통으로 유지하되, Phase 1에서 효과별 필요성 검토

### 4. 설정 순서
✅ **확인됨**: 효과 선택 → 속도/강도 등 공통설정 + 기본 텍스트 설정 → 개별 설정

## Phase 1 분석 결과 ✅

### 기존 슬라이딩 효과의 설정 스타일 확인
- **단순한 슬라이더**: `<input type="range">` 사용
- **라벨**: `<label className="block text-sm font-medium mb-2">`
- **버튼 그룹**: 2열 그리드 배치, 선택 시 파란색 배경
- **컨테이너**: `<div className="space-y-4">`

### 각 효과별 필요 설정 분석

#### 1. slide (슬라이딩)
- **사용 설정**: textConfig.speed (기존 속도 설정 활용)
- **불필요 설정**: 추가 개별 설정 없음
- **방향 설정**: 필요 없음 (항상 우→좌)

#### 2. typing (타이핑)
- **개별 설정**:
  - showCursor: 커서 표시 여부 (체크박스)
  - cursorBlinkSpeed: 커서 깜빡임 속도 (슬라이더)
- **방향 설정**: 필요 없음 (항상 순차적)

#### 3. rotate (회전)
- **개별 설정**:
  - direction: 'clockwise' | 'counterclockwise' | 'alternate' (드롭다운)
  - maxRotation: 최대 회전각도 (슬라이더)
- **방향 설정**: 자체 direction으로 대체

#### 4. shake (진동)
- **개별 설정**:
  - frequency: 진동 주파수 (슬라이더)
  - damping: 감쇠율 (슬라이더)
- **방향 설정**: 필요 없음

#### 5. bounce (바운스)
- **개별 설정**:
  - height: 바운스 높이 (슬라이더)
  - elasticity: 탄성력 (슬라이더)
- **방향 설정**: 필요 없음

#### 6. zoom (줌)
- **개별 설정**:
  - minScale: 최소 크기 (슬라이더)
  - maxScale: 최대 크기 (슬라이더)
- **방향 설정**: 필요 없음

#### 7. fade (페이드)
- **개별 설정**:
  - minOpacity: 최소 투명도 (슬라이더)
  - maxOpacity: 최대 투명도 (슬라이더)
- **방향 설정**: 필요 없음

#### 8. colorChange (색상변화)
- **개별 설정**:
  - smooth: 부드러운 전환 (체크박스)
  - colors: 색상 목록 (현재는 고정값, 향후 확장 가능)
- **방향 설정**: 필요 없음

### 공통 설정 검토 결과
- **duration & repeat**: ❌ 제거 (무한 루프만 제공)
- **direction**: ❌ 제거 (rotate 효과는 자체 direction 사용)
- **animationSpeed**: ✅ 유지 (모든 효과에서 사용)
- **animationIntensity**: ✅ 유지 (모든 효과에서 사용)

### 기본 텍스트 설정
- **모든 효과에 공통 적용**:
  - 텍스트 색상 (colorChange 제외)
  - 글자 크기
  - 수직 오프셋
- **slide 효과 전용**:
  - 속도 (textConfig.speed)
  - 간격 (textConfig.gap)
